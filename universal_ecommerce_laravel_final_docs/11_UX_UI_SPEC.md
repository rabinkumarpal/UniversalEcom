# UX/UI Specification

## Visual direction
Use the supplied screenshot as a UX reference:
- compact ecommerce header
- prominent search
- location/serviceability indicator
- category icon grid
- promotional hero
- horizontally browsable product collections
- dense but readable product cards
- strong green/yellow accent treatment can be replaced by original brand colors
- trust/promise sections
- testimonials
- large footer

Do not reproduce the exact brand identity or assets.

## Homepage sections
1. Announcement bar
2. Main header

## Product card
Must support:
- product image
- discount badge
- delivery badge
- product name
- rating/review count
- MRP
- selling price
- savings
- variant count
- quantity control
- Add button
- bulk-price indicator where applicable

## PLP
Desktop:
- left filter rail or filter drawer
- product grid
- sorting
- result count
- pagination/infinite loading

Mobile:
- sticky filter/sort bar
- 2-column product grid where appropriate

## PDP
Above fold:
- gallery
- product title
- rating
- SKU
- variant selector
- price
- quantity
- bulk price table
- stock
- delivery estimate
- add to cart
- buy now

Below:
- description
- specifications
- documents
- shipping/returns
- reviews
- related products

## Checkout
Use a short, confidence-building checkout:
1. address
2. delivery mode/slot
3. coupon/wallet
4. payment
5. confirmation

Show final payable amount clearly.

## Accessibility
- keyboard navigation
- visible focus states
- semantic headings
- labels for form fields
- accessible dialogs
- sufficient contrast
- alt text
- reduced-motion support

## Performance
- responsive images
- lazy-load below-fold media
- avoid huge JS bundles
- server-render public pages where possible
- prefetch only useful navigation
- use skeleton/loading states without blocking content unnecessarily
